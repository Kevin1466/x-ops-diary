# 数据说明

`metrics.csv` 每天一行，用来画趋势。空着就代表当天没记，不要填 0 混淆。

| 字段 | 含义 | 备注 |
|---|---|---|
| `date` | 日期 | `YYYY-MM-DD` |
| `followers` | 当日粉丝数 | X 个人主页显示的数字 |
| `following` | 当日关注数 | 用来监控关注率是否失衡 |
| `posts` | 当日发帖数 | 含回复但不含转推 |
| `impressions` | 当日所有帖子浏览总和 | 个人主页「帖子分析」里取 |
| `likes` | 当日总点赞 | 同上 |
| `reposts` | 当日总转推 | 同上 |
| `replies` | 当日总回复 | 同上 |
| `best_post` | 当日最佳帖链接 | 短链或完整 URL |
| `note` | 备注 | 当天做了什么实验 |

## 为什么用 CSV 不用 JSON

- 一行一天，`git diff` 看得清楚
- 直接拖进 Excel / Numbers / pandas，不用转换
- 每月最后一天可以顺手截个图放进 diary，形成可视化

## 取数方式

目前是手动：打开 X 的「帖子分析」，抄 4 个数字。等自动化稳定后再做回流。
